## 一、强化学习是什么

强化学习是机器通过**与环境交互**来实现目标的一种方法。核心是**序贯决策**——不是做一次预测就完事，而是要一步一步做决策，每个决策会影响后面的局面。

用一个循环来理解：

```
智能体(Agent) → 选动作(Action) → 环境(Environment)
     ↑                                    ↓
  新状态(State) + 奖励(Reward) ← 环境发生改变
```

每一轮：智能体看到当前状态，选一个动作，环境给出奖励和下一个状态，如此反复。智能体的目标是让**累积奖励的期望**最大。

智能体有三个关键要素：
- **感知**：知道自己现在处在什么状态（棋盘、路况、摄像头画面等）
- **决策**：根据状态选出动作，这叫**策略(Policy)**，是不同智能体的核心区别
- **奖励**：环境给的一个标量反馈，告诉智能体这一步做得好不好

> 注意：当前奖励最大的动作，长期来看不一定最优。比如下棋时主动送个子，可能是为了后面更大的优势。

## 二、马尔可夫决策过程（MDP）

强化学习的环境一般可以抽象成 MDP，由五个元素组成：

| 符号 | 含义                                                 |
| ---- | ---------------------------------------------------- |
| S    | 状态集合                                             |
| A    | 动作集合                                             |
| P    | 状态转移函数：在状态s做动作a后，到下一个状态s'的概率 |
| R    | 奖励函数：在状态s做动作a能拿到多少奖励               |
| γ    | 折扣因子，0~1之间，越接近1越看重长远奖励             |

### 几个重要概念

**回报(Return)**：从某一步开始到结束，所有奖励按折扣累加起来。
$$G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + ...$$

**价值函数(Value Function)**：一个状态的期望回报，也就是从这个状态出发，按当前策略走下去平均能拿多少分。
- 状态价值 V(s)：处于状态s的价值
- 动作价值 Q(s,a)：在状态s选动作a的价值

**贝尔曼方程**：价值函数可以拆成"即时奖励 + 下一步价值的折扣"，这是后面所有算法的基础。

**策略(Policy)**：智能体在每个状态下选动作的规则。
- 确定性策略：一个状态只对应一个动作
- 随机性策略：一个状态对应动作的概率分布，按概率采样

## 三、常见强化学习算法

### 1. 表格型算法（状态动作少的时候用）

| 算法         | 特点                                                   |
| ------------ | ------------------------------------------------------ |
| 动态规划(DP) | 需要知道环境的转移概率和奖励函数，直接解方程           |
| 蒙特卡洛(MC) | 不需要知道环境模型，玩完整局后用实际回报更新价值       |
| 时序差分(TD) | 结合上面两者，不用等一局结束，走一步就更新             |
| Sarsa        | on-policy，用当前策略实际走的动作来更新                |
| Q-learning   | off-policy，直接取下一状态的最大动作价值来更新，更激进 |

Q-learning 的更新公式很简单：
$$Q(s,a) \leftarrow Q(s,a) + \alpha[r + \gamma \max_{a'} Q(s',a') - Q(s,a)]$$

就是让当前Q值往"即时奖励 + 下一步最大Q值"这个目标靠近。

### 2. 深度强化学习（状态多/连续的时候用）

状态太多（比如图像输入），表格存不下，就用神经网络来拟合Q值或策略。

| 算法             | 思路                                                      | 适用场景             |
| ---------------- | --------------------------------------------------------- | -------------------- |
| **DQN**          | 用神经网络拟合Q函数，加经验回放和目标网络稳定训练         | 连续状态、离散动作   |
| **策略梯度(PG)** | 直接优化策略网络，按奖励大小调整动作概率                  | 连续/离散动作都行    |
| **Actor-Critic** | 一个网络选动作(Actor)，一个网络评估价值(Critic)，互相配合 | 通用，收敛更稳       |
| **PPO**          | 策略梯度的改进版，限制每次更新幅度，训练稳，工业界常用    | 通用，目前最主流之一 |
| **DDPG/SAC**     | 面向连续动作的深度算法，比如机器人关节控制                | 连续动作空间         |

### DQN 的两个关键设计

DQN 是深度强化学习的开山之作，两个技巧让训练能收敛：

- **经验回放(Experience Replay)**：把交互数据存进缓冲区，训练时随机采样，打破数据之间的时序相关性，同时提高样本利用率。
- **目标网络(Target Network)**：用两套Q网络，训练网络每步更新，目标网络隔N步才同步一次。因为TD目标里本身就有网络输出，目标一直在变会导致训练震荡，固定目标网络就稳了。

## 四、强化学习的训练流程

以 DQN 为例，典型训练循环长这样：

```
1. 初始化Q网络和目标网络，初始化经验回放池
2. 循环很多个episode（一局游戏）：
   a. 重置环境，拿到初始状态
   b. 循环直到游戏结束：
      - 用ε-贪婪策略选动作（大部分时间选Q值最大的，小概率随机探索）
      - 执行动作，拿到奖励和下一个状态
      - 把 (状态, 动作, 奖励, 下一状态) 存进回放池
      - 回放池数据够了之后，随机采样一批数据
      - 用目标网络算TD目标：r + γ * max Q_target(s')
      - 用均方误差损失更新Q网络
      - 每隔N步把Q网络参数同步给目标网络
   c. 记录这一局的总回报，观察训练曲线
```

训练过程中看回报曲线是否上升，就能判断学得好不好。DQN在CartPole环境上大概100局后性能就会明显提升。

**ε-贪婪策略**是平衡探索与利用的常用手段：ε概率随机选动作（探索未知），1-ε概率选当前最优动作（利用已知）。训练初期ε大一些多探索，后期可以慢慢降下来。

## 五、奖励函数的意义与设计

奖励函数是强化学习的"指挥棒"——智能体完全按照奖励来调整行为，奖励设计得好不好直接决定能不能学到想要的策略。

### 奖励的作用
- 告诉智能体什么是"好"，什么是"坏"
- 是智能体学习的唯一反馈信号
- 累积奖励的期望就是优化目标

### 设计奖励函数的要点

1. **稀疏奖励 vs 密集奖励**
   - 稀疏：只有完成目标才给奖励（比如下棋赢了才+1），学得慢但目标明确
   - 密集：每一步都给小奖励（比如走一步+0.1），学得快但容易跑偏

2. **奖励塑形(Reward Shaping)**
   - 在主奖励之外加一些引导性的中间奖励，帮助智能体更快找到方向
   - 比如机器人走路，除了"到达终点+100"，再加"每往前走一步+0.1"
   - 风险：引导得不好会让智能体钻空子（比如来回走刷小奖励）

3. **惩罚项**
   - 不希望的行为给负奖励，比如摔倒-10、耗能-0.01
   - 注意惩罚不能太大，否则智能体可能学会"什么都不做"来避免惩罚

4. **折扣因子γ的选择**
   - γ接近1：看重长远回报，适合需要规划的任务
   - γ接近0：只看眼前奖励，适合即时反馈的任务

### 一个常见的坑

奖励函数设计不当会导致"奖励黑客"——智能体找到了刷奖励的捷径，但不是我们真正想要的行为。比如训练机器人跑步，奖励是"向前移动的距离"，结果机器人学会了原地快速摆腿而不前进。设计时要反复想：这个奖励真的对应我想要的行为吗？

## 六、强化学习 vs 有监督学习 vs 无监督学习

### 和有监督学习的对比

| 维度     | 有监督学习               | 强化学习                                           |
| -------- | ------------------------ | -------------------------------------------------- |
| 数据     | 给定固定数据集，分布不变 | 智能体自己和环境交互产生数据，策略变了数据分布就变 |
| 反馈     | 每个样本有明确标签       | 只有奖励信号，可能延迟很久才知道对错               |
| 目标     | 最小化预测误差           | 最大化累积奖励期望                                 |
| 决策轮次 | 单轮独立预测             | 多轮序贯决策，当前动作影响未来                     |
| 优化方式 | 改模型参数，数据分布不变 | 改策略，数据分布跟着变，奖励函数不变               |

本质区别：有监督学习是"在固定数据分布上学一个函数"，强化学习是"通过改变策略来改变数据分布，从而让奖励期望最大"。强化学习更难，因为数据分布一直在变，像一个混沌系统。

### 和无监督学习的对比

无监督学习是在没有标签的数据里找结构（聚类、降维、生成），没有明确的"好坏"反馈。强化学习虽然也没有标签，但有**奖励信号**作为引导，目标明确得多。

### 三者的关系

- 有监督/无监督学习主要解决**预测和表征**问题
- 强化学习主要解决**决策**问题
- 实际中经常结合用：比如用无监督学习提取图像特征，再喂给强化学习做决策；用模仿学习（有监督）预训练策略，再用强化学习微调

## 七、应用场景

- **游戏AI**：AlphaGo、Atari游戏、StarCraft、Dota2
- **机器人控制**：机械臂抓取、四足机器人行走、无人机飞行
- **推荐系统**：优化长期用户留存，而不是单次点击率
- **自动驾驶**：规划行车轨迹和决策
- **资源调度**：数据中心冷却、网络路由、芯片设计
- **金融**：量化交易、投资组合管理
- **医疗**：治疗方案优化、用药剂量调整

## 八、小结

强化学习的核心思路其实很朴素：**多做能拿到高奖励的动作，少做拿低奖励的动作**。难点在于：
1. 奖励可能延迟，要搞清楚到底是哪一步导致了最终结果
2. 要平衡探索（试试新动作）和利用（用已知好的动作）
3. 数据分布随策略变化，训练不稳定
4. 奖励函数设计不好，智能体可能学到奇怪的行为

不用纠结数学推导，先理解"智能体-环境-奖励-策略"这个循环，再搞懂Q-learning和DQN的思路，就算入门了。
